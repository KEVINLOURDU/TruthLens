Project Introduction & Objectives

Machine Learning Research

The proliferation of misinformation across online digital ecosystems poses significant challenges to public trust, democratic governance, and societal cohesion. TruthLens is an end-to-end Machine Learning web application designed to automatically classify news articles as FAKE or REAL using five established, complementary supervised classification algorithms.

Objective 1: Multi-Model Evaluation

Train and contrast five distinct mathematical classifiers on a standardized, stratified test split.

Objective 2: Majority Consensus

Synthesize individual probabilistic and hyperplane decisions through hard ensemble voting.

Objective 3: Multilingual Usability

Empower regional language speakers with localized UI navigation in English, Tamil, Hindi, Telugu, and Kannada.

Mathematical Breakdown of The 5 Classifiers

Scikit-Learn Implementation

1. Logistic Regression (max_iter=1000, C=1.0)

Logistic Regression is a linear classification model that estimates the probability of the positive class (Real News) by applying the sigmoid function \(\sigma(z) = \frac{1}{1 + e^{-z}}\) to a linear combination of TF-IDF feature weights. Regularization parameter \(C=1.0\) controls L2 weight decay to prevent overfitting on sparse n-gram vocabularies.

2. Multinomial Naive Bayes (alpha=0.5)

Multinomial Naive Bayes models the probability distribution of word occurrences given the target category using Bayes' Theorem with the assumption of conditional feature independence: \(P(c|x) \propto P(c) \prod P(x_i|c)\). The Laplace smoothing factor \(\alpha=0.5\) handles out-of-vocabulary and zero-frequency tokens.

3. Decision Tree (max_depth=50)

The Decision Tree recursively splits the feature space using orthogonal binary decision thresholds based on Gini Impurity: \(I_G(p) = 1 - \sum p_i^2\). Limiting tree depth to 50 prevents memorization of noise while capturing salient lexical cues.

4. Random Forest (n_estimators=100, max_depth=50)

Random Forest constructs an ensemble of 100 decorrelated decision trees, each trained on a bootstrap sample of the training data with random feature subsampling at each candidate split. Aggregating individual tree votes significantly dampens variance and provides superior generalization.

5. Support Vector Machine – Linear Kernel (C=1.0)

Linear Support Vector Classification (LinearSVC) constructs an optimal separating hyperplane that maximizes the geometric margin between Real and Fake news classes in 5,000-dimensional TF-IDF space. Linear SVM is renowned for high efficiency and robustness in high-dimensional text classification.

Technologies Used

  • Backend Framework: Python 3 & Flask
  • Machine Learning: Scikit-Learn (TF-IDF, LinearSVC, LogisticRegression, etc.)
  • Data Wrangling: Pandas & NumPy
  • Model Serialization: Joblib for instant inference
  • Interactive Charts: Chart.js 4.4
  • Styling & Layout: Clean Minimal CSS3 & Lucide Icons
  • Multilingual Engine: Dynamic Client-Side Localization

Advantages & Limitations

Advantages:

Sub-millisecond inference time; lightweight footprint without GPU dependency; multi-model majority voting provides robust checks against individual model bias; transparent evaluation metrics.

Limitations:

TF-IDF bag-of-words ignores long-range syntactic nuances; models trained on English articles cannot yet accurately classify non-English text directly; predictions reflect statistical patterns rather than real-time live fact verification.
